# Contributing
Este arquivo explica como **contribuir** para este projeto.

## Requisitos
Antes de contribuir:
- Tenha o **Git** instalado
- Saiba o básico de **Git** e **GitHub** (clone, commit, push, pull request)

## Como contribuir
1. Faça um fork do repositório
  
2. Clone o fork para sua máquina
```md
```bash
git clone URL_DO_SEU_FORK
```

3. Crie uma branch para sua alteração
```md
```bash
git checkout -b minha-branch
```
4. Faça suas alterações

5. Commit com uma mensagem clara
```md
```bash
git commit -m "Descrição curta do que foi feito"
```

6. Envie para o GitHub
```md
```bash
git push origin minha-branch
```

7. Abra um Pull Request

## Padrões
- Código organizado e legível
- Não subir código quebrado
- Testar antes de enviar
- Evitar commits gigantes

## Commits
- Use mensagens simples e objetivas.
Exemplo:
- `fix: corrige erro no botão`
- `feat: adiciona página de login`
- `refactor: melhora organização do código`

## Issues
- Use Issues para bugs, sugestões ou melhorias
- Explique claramente o problema ou ideia

## Observações finais
- Seja respeitoso
- Comentários construtivos apenas
- Dúvidas são bem-vindas
